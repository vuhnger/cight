**Users**
Developers working in VS Code or in Claude Code in the terminal. They avoid the slow browser and want a menu bar signal only when they must act.

**Version 1**
GitHub Actions status for your repos, in the menu bar. Later, maybe tagging AI agents or restarting jobs.

**Purpose to keep**
A super fast CI overview and the ability to act on it.

**Platform**
macOS 26, Swift 6, SwiftUI in AppKit, no dependencies.
